# AI Assisted Charting for Registered Nurses

Project for my Internship at Xavor Corporation

## Description
This project was made in collaboration with Practicing Nurses from University of California, Irvine. Aim was to help the nurses document their actions in code scenarios like use of epinephrine, ventilators etc. Nurses just have to speak with the device and the audio will be transcribed and formatted automaticaly and also a table would be generated about the administration of life saving drugs and their timelines.

## Technology Used
Frontend:              Flutter

Sound Recognition:     OpneAI's Whisper Model

Report Generation:     GPT-4
